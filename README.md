# eLabFTW Usage Data Analysis

Data analysis project focused on evaluating usage patterns, user activity, and structured feature adoption within the eLabFTW electronic laboratory notebook platform.

---

## Project Overview

This project was developed as part of an IHK final project in cooperation with the Center for Information and Media Technology (ZIM) at Heinrich Heine University Düsseldorf.

The goal was to analyze usage and process data from the eLabFTW platform using SQL and Python in order to develop KPIs and identify optimization potential for platform usage, onboarding, and reporting.

---

## Objectives

- Analyze user activity and inactivity
- Evaluate team-based usage distribution
- Measure experiment lifecycle metrics
- Analyze structured feature adoption
- Develop reproducible KPI analysis workflows
- Support data-driven decision-making

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- SQL / MySQL
- Jupyter Notebook
- Excel

---

## Key KPIs

- Active vs. inactive users
- Experiment volume per team
- Experiment lifecycle duration
- Structured feature usage
- Resource linking frequency
- External link / DOI usage

---

## Sample Analysis Areas

- User activity analysis
- Team activity distribution
- Experiment lifecycle analysis
- Feature usage evaluation
- KPI reporting and visualization
